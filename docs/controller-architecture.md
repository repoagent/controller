# Controller core and adapters

The controller follows [ADR 0010](adr/0010-structure-the-controller-and-broker-as-ports-and-adapters.md). `RepoAgentController.Core` owns decisions over domain types and injected ports; `RepoAgentController` owns files, processes, provider protocols, HTTP and command-line composition. The core's banned-API analyzer rejects common I/O, wall-clock and `JsonNode` APIs.

| Core responsibility | Adapter responsibility |
| --- | --- |
| `GitHubTokenLifetime` owns renewal, expiry, rejection and its `IAgentToolCredentials` binding. Tools can read only the currently usable token; a tool read never renews it. | `CredentialHandoff` serves the private Unix socket and its nonsecret pointer. Its wire messages and filesystem permissions stay outside Core. |
| `ControllerPolling` observes immediately, waits after each completed pass, separates intake stop from entered activity, and flushes durable output for `--once`. | The command line selects polling mode and supplies the interval and lifetime tokens. |
| `ControllerWebhooks` admits typed authenticated observations, excludes the dashboard and App comments, coalesces pending Discussion reads, reconciles periodically and registers/deactivates the webhook. A bound default-ref push persists a checkout hint before acknowledgement. | `DiscussionWebhooks` authenticates signatures, bounds HTTP body reads, translates provider payloads and maps dispositions to HTTP responses. `ControllerHttpServer` owns Kestrel, routing and listener isolation. |
| `Bridge.ReplaceAgentCredentials` excludes dispatch and requires both settled agent activity and proven checkout idle before replacing credentials. An admission that cannot prove global idle refuses replacement. | The credential-file watcher detects and validates a changed supply; the command line wires it to the core operation. |
| `ControllerStatus` and `StatusSnapshot` project stored work and current activity into operator and busy/idle status. | HTTP and CLI adapters serialize those domain snapshots. |

`BridgeCommand` remains the composition root: it parses options, validates external paths and coordinates, acquires leases, constructs adapters and translates process stop/authority loss into lifetime cancellation. It does not decide webhook admission or the ordering of credential replacement.

Once admission has permanently stopped for shutdown, replacement credentials cannot restart the agent runtime, even when it is already idle.

## Verification ownership

Core characterizations use the real bridge, sessions, status and outbox with in-memory ports and controlled time. `ControllerWebhooksTests` covers observation, duplicate coalescing, a change arriving during a read, failed-read recovery, periodic reconciliation, normal stop and durable push hints. `GitHubTokenLifetimeTests` includes agent-tool publication ownership; `AgentCredentialReplacementTests` covers runtime and checkout idle exclusion. Polling and status projection retain their existing core suites.

The former process-only Discussion-dispatch and busy/idle decision cases are replaced by these core tests. HTTP serialization, listener/signature/body-deadline safety, OS-signal shutdown, descendant termination and proof that bearer tokens do not reach persistent outputs retain their existing host/process checks. Those tests protect process and transport facts, rather than substituting executable stand-ins for core decisions. This change adds no separate provider adapter contract suite.

Actual pinned Codex/GitHub translation and installer compatibility remain with the [shared Aspire journey](../service/auth/local-development.md) and [hosted smoke gate](ci-cd.md). In-process characterizations and host fixtures do not establish real-provider acceptance.
## Owned agent process shutdown

Broker-mode teardown keeps ownership until the agent and its captured descendants are no longer executing. Normal stop first drains accepted turns; credential loss aborts owned work. The adapter starts a fixed `/bin/sh` supervisor with .NET 11's `ProcessStartInfo.StartDetached`, creating a new Unix process session on Linux and macOS. The agent executable is resolved before launch and passed with its arguments as argv, without shell interpolation. Shell startup hooks, imported functions and tracing options are excluded. The literal supervisor saves incoming stdin on a separate descriptor, launches that argv exactly once with the saved descriptor as stdin, and closes both extra descriptor copies. It then uses only shell builtins. Redirected JSON-RPC pipes remain connected. Terminal signals reach the controller's process group, while accepted agent work drains under controller supervision.

`OwnedAgentProcesses` shares one termination task between the credential-loss callback and disposal. A fixed private stderr notice proves the supervisor has performed its only fork. It then pins the session identity while every other owned session member is captured and frozen. The supervisor stays alive after agent exit until controller stdin closes; broker teardown keeps that stdin open. This avoids the pinned runtime's macOS SIGCHLD loop spinning when a tracked managed child is frozen. Descendants are terminated and confirmed non-executing before the supervisor is terminated and confirmed last. A short-lived helper can exit during capture without losing its reparented children: they retain the owned Unix session. Different process groups in that session remain covered. An observable descendant that creates another Unix session is adopted only after its relationship to the trusted supervisor or a frozen owned parent and its own frozen witness are established. Lost witness/session proof fails rather than authorizing a wider kill.

The supervisor reports actual agent exit through another fixed stderr notice, closes its own output streams and waits for controller EOF. The adapter reports disconnect and fails pending requests promptly even if a descendant inherited the agent's output pipes; later notifications cannot reopen admission. The notices carry only launch/exit state and a numeric agent exit status, and are filtered from agent stderr logs. `agent-exited` records that actual status. A supervisor killed during teardown has its own termination status, which is not presented as the agent's exit status. Graceful supervisor exit preserves the agent's status. No provider body or credential is part of this control protocol.

The adapter rechecks process start-time identity and Unix session before signaling. It uses fixed system `/bin/ps` process-ID/parent-ID/state columns and the platform `getsid` function, never agent-controlled `PATH`, process command lines or environments. It does not publish the host inventory. Capture and confirmation have a five-second budget, a 512-captured-process cap and an 8,192-row/128-character-line observation cap; interrupted observer cleanup has a separate one-second exit bound. Internal budget expiration is a failure, distinct from successful user cancellation. Best-effort failure cleanup cannot turn uncertainty into success.

This is lifecycle ownership, not OS containment or historical orphan discovery. A process that creates an independent session and loses its observable ancestry before capture cannot be attributed retroactively; that preexisting `Process.Kill(tree)` limit remains. The adapter does not reap arbitrary reparented processes or infer authority from a numeric PID alone. Its launch-time Unix session improves coverage of ordinary reparented descendants, and known live identities remain retained through termination.

The existing real-process gates keep the immediate post-return Linux non-execution assertion, copied-credential holders, unrelated-process and retained-state checks. Added grandchildren cover a different process group and an observable independent Unix session. The actual CLI signal test checks SIGTERM and foreground-process-group SIGINT, withholding completion beyond the old two-second termination budget. macOS uses its system process-state observation; the Controller workflow runs those same OS/credential-handoff and signal classes in a separate bounded job with actual execution and no skips required. Source compilation or Linux results do not establish a macOS pass. No core port or fake provider adapter suite is added.
